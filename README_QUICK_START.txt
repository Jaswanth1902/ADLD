🚀 INSTANT DEMO (Recommended)
─────────────────────────────────────────────────────────────────────────────

  Double-click:  START_DEMO.bat

  This will launch the interactive demo in your browser instantly!


📋 KEYBOARD SHORTCUTS IN DEMO
─────────────────────────────────────────────────────────────────────────────

  5        - Insert ₹5 coin
  1        - Insert ₹10 coin
  S        - Select item  
  R        - Reset system
  D        - Run automatic demo sequence
  Space    - Next clock cycle (in step-by-step mode)

🔬 VERILOG SIMULATION (Optional - Requires Installation)
─────────────────────────────────────────────────────────────────────────────

  1. Install Icarus Verilog: http://bleyer.org/icarus/
  2. Install GTKWave: http://gtkwave.sourceforge.net/
  
  Then run:
    cd verilog
    iverilog -o sim.vvp *.v
    vvp sim.vvp
    gtkwave waveform.vcd
