🔄 FSM Design

State Descriptions

IDLE

Waiting for coin insertion. All outputs inactive.

ACCEPT_COIN

Processing coin input, updating credit register.

WAIT_SELECTION

Sufficient credit available, waiting for item selection.

DISPENSE_ITEM

Item selected, activating dispense mechanism.

RETURN_CHANGE

Returning excess credit as change.

Why FSM for Microcontrollers?

Finite State Machines are fundamental to embedded systems and microcontroller programming:

  • Deterministic Behavior: Each state has well-defined transitions and outputs
  • Low Resource Usage: Minimal memory footprint, ideal for resource-constrained MCUs
  • Easy Verification: State-based logic simplifies testing and debugging
  • Firmware-Friendly: Directly translates to embedded C state machines
  • Real-Time Response: Predictable execution time for each state transition

💻 Verilog Implementation

Control FSM (Excerpt)

// State transition logic
always @(posedge clk) begin
    if (reset)
        current_state <= IDLE;
    else
        current_state <= next_state;
end

// Next state combinational logic
always @(*) begin
    case (current_state)
        IDLE: begin
            if (coin_5_detected || coin_10_detected)
                next_state = ACCEPT_COIN;
        end
        
        ACCEPT_COIN: begin
            if (current_credit >= ITEM_COST)
                next_state = WAIT_SELECTION;
            else
                next_state = IDLE;
        end
        
        WAIT_SELECTION: begin
            if (select_detected)
                next_state = DISPENSE_ITEM;
            else if (coin_5_detected || coin_10_detected)
                next_state = ACCEPT_COIN;
        end
        // ... more states
    endcase
end

Credit Register Module

always @(posedge clk) begin
    if (reset) begin
        credit_out <= 8'd0;
    end
    else if (enable) begin
        if (load) begin
            // Add coin value to credit
            if (credit_out + credit_in > 8'd255)
                credit_out <= 8'd255;
            else
                credit_out <= credit_out + credit_in;
        end
        else if (decrement) begin
            // Subtract item cost
            if (credit_out >= 8'd15)
                credit_out <= credit_out - 8'd15;
        end
    end
end
